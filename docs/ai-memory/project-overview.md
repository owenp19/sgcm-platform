# Project Overview - OCCRE

## Descripción
Sistema de Gestión y Control Migratorio Raizal (SGCM/OCCRE). Plataforma para gestión migratoria con aplicaciones web responsive y Android (APK).

## Stack Tecnológico
- **Frontend**: Angular 20, Ionic 8, TypeScript 5.9, Capacitor 8
- **Backend**: Laravel 12, PHP 8.2
- **Base de datos**: MySQL
- **Autenticación**: JWT (tymon/jwt-auth)
- **Plataformas**: Web responsive, Android (Capacitor), iOS preparado
- **Otros**: Chart.js, Leaflet, QR, Firebase, DomPDF, Excel

## Ubicación
- Raíz: Frontend Angular/Ionic
- `backend/`: API Laravel REST
- `android/`: Proyecto Android Capacitor
- `ios/`: Proyecto iOS Capacitor

## Contexto
Instalación completa de skills desde cero - FASE 0. Sin skills locales previas.
